QUICK REFERENCE: How the Visual Highlighting Works
==================================================

1. USER PRESSES ARROW KEY
-------------------------
TextBox has focus, user types to filter, then presses Down arrow

2. BEHAVIOR INTERCEPTS KEY
--------------------------
TextBox_PreviewKeyDown(sender, e)
    -> e.Handled = true  // Prevent default ComboBox behavior
    -> view.MoveCurrentToPosition(newIndex)  // Update data layer
    -> HighlightItem(comboBox, newIndex)  // Update visual layer

3. CLEAR PREVIOUS HIGHLIGHT
---------------------------
ClearHighlight(comboBox)
    -> Get previous index from HighlightedIndexProperty
    -> Get previous ComboBoxItem container
    -> SetIsKeyboardHighlighted(previousContainer, false)
    -> Style trigger removes blue background

4. APPLY NEW HIGHLIGHT
----------------------
ApplyHighlight(comboBox, container, index)
    -> SetIsKeyboardHighlighted(container, true)  // Set custom attached property
    -> container.BringIntoView()  // Scroll if needed
    -> Style trigger applies blue background (SystemColors.HighlightBrush)

5. STYLE TRIGGER RESPONDS
-------------------------
In ItemContainerStyle (auto-generated by behavior):
<Trigger Property="behaviors:ComboBoxKeyboardBehavior.IsKeyboardHighlighted" Value="True">
    <Setter Property="Background" Value="{x:Static SystemColors.HighlightBrush}"/>
    <Setter Property="Foreground" Value="{x:Static SystemColors.HighlightTextBrush}"/>
</Trigger>

6. USER SEES VISUAL FEEDBACK
----------------------------
- Blue background on highlighted item
- White text
- Automatic scrolling if item is off-screen
- Focus STAYS on TextBox (can still type to filter!)

KEY INSIGHT: Why This Works
============================
We're using WPF's styling/trigger system instead of focus
- IsKeyboardHighlighted is just a bool property
- Style trigger watches this property
- When true ? apply highlight styling
- When false ? remove highlight styling
- NO FOCUS CHANGES ? TextBox keeps focus ? Filtering still works!

Alternative Approaches That DON'T Work:
=======================================
? container.Focus() ? Steals focus from TextBox, breaks filtering
? comboBox.SelectedItem ? Changes actual selection, unwanted
? IsHighlighted property ? Read-only, can't set it
? IsSelected property ? Conflicts with real selection
? Visual state manipulation ? Too complex, fragile
? Custom attached property + Style trigger ? Perfect!

Debug Output You Should See:
============================
Moving selection from 0 to 1
Highlighted item at index 1: [YourItemObject]
(If you see "WARNING: Could not generate container" ? virtualization issue, retry will handle it)

Common Issues and Fixes:
========================
Issue: No highlight appears
Fix: Check that ItemContainerStyle was generated (see EnsureItemContainerStyle)

Issue: Highlight but TextBox loses focus
Fix: Make sure you're using SetIsKeyboardHighlighted, NOT Focus()

Issue: Multiple items highlighted
Fix: Verify ClearHighlight is called before ApplyHighlight

Issue: Highlight doesn't scroll into view
Fix: Check BringIntoView() is being called on container

Issue: Container is null
Fix: Normal for virtualized lists, retry logic handles it (see BeginInvoke)
